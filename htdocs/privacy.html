Data collected when browsing the database

When you access any page of this website, your web browser transmits the following information to the server:

  • Your IP address
  • The version number of your web browser and operating system
  • In some cases, the website you were browsing before visiting this website

Together with information about which pages were accessed and any errors that occurred during that access, this information is stored temporarily (no longer than [RETENTION PERIOD HERE]) for the following purposes:

  • To identify and prevent abuse (for example, to identify denial-of-service attacks originating from an IP address)
  • To diagnose and fix problems with the website

This website is served through Cloudflare, which acts as a reverse proxy. As a result Cloudflare also receives and processes the information above, under its own privacy policy, before requests reach this server.

No cookie is set when you merely browse the database. A cookie is set only when you sign in, as described below.

Data collected when contributing

This database is a public, collaborative effort. By submitting a contribution, you are choosing to make it public. As such, it is your responsibility not to include personal data in your contribution which you do not wish to be public. This includes the contents of any screenshot you attach.

Contributing through the website requires you to sign in with your GitHub account. Signing in is used to attribute your contributions to you:

  • Your contributions are publicly attributed to your GitHub username
  • Moderation actions may be informed by your contribution history and identity

When you sign in with GitHub, only the following information will be collected:

  • Your GitHub username
  • Your GitHub account's unique ID number (so you can still be recognised if you change your username)

If you do not make any contributions, then this information is only stored for as long as you remain signed in, plus a short period of time after this while it awaits deletion (no longer than [RETENTION PERIOD HERE]). If you do make a contribution, then your GitHub username and GitHub account ID number will be stored in the database, and your GitHub username will be publicly displayed alongside your contributions. If every one of your contributions is later deleted, then your GitHub username and account ID number are removed from the database.

If you have changed your GitHub username, signing in will update the publicly displayed username on your past contributions.

A cookie will be set when you sign in. This cookie is only used for the attribution described above.

Please note that signing in with GitHub also involves the processing of your data by GitHub, which has a separate privacy policy.

Screenshots

A compatibility report may include a screenshot of the emulated application. Screenshots are stored in the database and displayed publicly alongside the report. They are supplied by the contributor, so a screenshot may show whatever was on the emulated screen at the time; do not attach one containing anything you do not wish to publish.

Contributions submitted programmatically

Reports may also be submitted through an authenticated interface used by automated tools, such as the coding agents that work on tapHLE itself. These submissions are attributed to the name of the tool that produced them (for example, a model or program name), not to a person, and involve no GitHub sign-in and no cookie. Like every other submission, they are not published until a moderator approves them.

The tapHLE emulator does not currently send any information to this database. If automatic reporting is added to the emulator in future, it will be optional, and this policy will be updated to describe exactly what it sends before it is enabled.

Moderators

Moderators approve and delete contributions. If you are a moderator, your moderation decisions are recorded in the database and attributed to your GitHub username, and that attribution is visible to other moderators.

Licensing of contributions

Contributions to the database are published under the licence named in the footer of every page. Once a contribution is public, copies of it may exist elsewhere beyond the operator's control, so deletion from this database cannot guarantee deletion everywhere.
